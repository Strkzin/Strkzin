## &nbsp;&nbsp;Sobre

> Construo e **opero** o que entrego. Código, deploy, backup, certificado e o plantão de domingo.

Analista de TI no **CREA-PE**, onde migrei o portal institucional de WordPress para uma stack própria em **Next.js + Strapi** e mantenho a infraestrutura que a sustenta.

Fora do expediente, desenvolvo sistemas sob medida para quem ainda resolve tudo no papel: prontuário eletrônico de clínica, gestão de feiras, carona corporativa. Também conduzo testes de intrusão autorizados e escrevo os laudos de divulgação responsável.
